# Fill-in templates

Copy these files to a private company drive, rename them with the date, and complete them. Do not commit completed records to this repository: they contain names, security details, and supplier information.

- `asset-inventory.csv`: what you own and who manages it.
- `risk-register.csv`: risks, remediation, and accepted risk.
- `access-review.csv`: proof that access was reviewed.
- `supplier-register.csv`: vendors that receive data or privileged access.
- `incident-report.md`: complete during exercises and real incidents.
- `quarterly-security-review.md`: agenda and minutes for governance evidence.
